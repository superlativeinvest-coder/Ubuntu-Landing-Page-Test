# CLAUDE_DESIGN_SYSTEM.md --- UBUNTUSPEAKS Design System

## Design Intent

The website must feel like a premium consulting firm website.

Characteristics: - clean - minimal - executive - structured - modern

Avoid: - SaaS dashboard styling - influencer landing page aesthetics -
coaching funnel visuals

------------------------------------------------------------------------

# Mobile‑First Design

Design must prioritize mobile devices.

Rules:

-   No horizontal scrolling
-   Large readable typography
-   Buttons sized for thumb tapping
-   Content stacked vertically
-   CTA visible early (above the fold)
-   Text readable without zooming

Most visitors will first view the site on their phone.

------------------------------------------------------------------------

# Brand Colors

Primary Brand Colors

Navy Blue --- #000080\
Orange --- #F48309\
Black --- #000000

Recommended usage ratio:

70% Navy\
20% White\
10% Orange

Orange should be used primarily for **CTA buttons and highlights**.

------------------------------------------------------------------------

# Typography

Heading Font\
Playfair Display

Body Font\
Inter

Heading rules:

Tracking: -0.03em\
Large headings should feel editorial and authoritative.

Body rules:

Line height: 1.7\
Readable on mobile devices.

------------------------------------------------------------------------

# Spacing Tokens

Use consistent spacing tokens throughout the layout.

4px\
8px\
16px\
24px\
32px\
48px\
64px\
96px

Sections should include generous vertical spacing.

------------------------------------------------------------------------

# Responsive Layout

Desktop Layout:

-   2--3 column grids
-   spacious margins
-   strong visual hierarchy

Mobile Layout:

-   single column layout
-   stacked cards
-   vertical reading flow
-   large CTA buttons

Design should always degrade gracefully from desktop → tablet → mobile.

------------------------------------------------------------------------

# Visual Hierarchy

Each page should follow a clear visual hierarchy:

1.  Headline
2.  Supporting subheadline
3.  Key content blocks
4.  Services or outcomes
5.  CTA

Avoid cluttered sections.

White space is intentional and improves readability.

------------------------------------------------------------------------

# Interaction Principles

Buttons must include:

-   hover state
-   focus state
-   active state

Animations should be minimal and professional.

Allowed:

-   transform
-   opacity

Avoid heavy animations or distracting motion.

------------------------------------------------------------------------

# Accessibility

Ensure:

-   sufficient color contrast
-   readable font sizes
-   buttons accessible on mobile
-   logical heading structure
